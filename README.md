# Teachers’ Day Message Card

A responsive, book-style digital greeting card made with HTML, CSS, and JavaScript for **Mr. Randy Bello**, from **Lorraine Joyce Valler**.

## Features
- Animated book/page-flip effect with Previous and Next controls.
- Customizable teacher name, student name, and message.
- Message can also be edited directly on the inside page.
- Upload a photo from your device.
- Play/pause the included audio track or upload your own audio.
- Responsive layout for desktop and mobile screens.
- Reset button to restore the original message.

## Project files
- `index.html` — page structure and card content.
- `style.css` — visual design, responsive layout, and page-flip animation.
- `script.js` — page navigation, editable message, photo/audio upload, and playback.
- `assets/teacher-photo.png` — starter portrait image.
- `assets/background-music.m4a` — optional supplied audio track.

## How to run
1. Download or clone this repository.
2. Keep the `assets` folder beside `index.html`.
3. Open `index.html` in a modern browser (Chrome, Edge, Firefox, or Safari).
4. Use **Next** to turn the pages. Edit the fields on the right and select **Update card**.
5. Use **Add / change photo** or **Add audio** to select files from your device. Click **Play music** to start playback; browsers require a user click before audio can play.

No build tools or server are required for local use.

## Publish on GitHub
1. Sign in to GitHub and create a **public** repository, for example `teachers-day-message-card`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the complete `assets` folder.
3. Commit the files.
4. To publish it as a website, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
5. After GitHub Pages finishes publishing, your site link will look like `https://YOUR-USERNAME.github.io/teachers-day-message-card/`. Replace `YOUR-USERNAME` with your GitHub username.

## Customize
- Update the default names/message in `index.html` and in the reset values in `script.js`.
- Replace `assets/teacher-photo.png` with a photo you have permission to use, keeping the same filename, or change the image path in `index.html`.
- Replace `assets/background-music.m4a` with audio you have permission to use, keeping the same filename, or choose a different file in the card's audio uploader.
- For a public website, make sure you have permission to share any photo or music file you upload. An uploaded file selected using the browser controls is temporary and is not automatically added to the GitHub repository.
